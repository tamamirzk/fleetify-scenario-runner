Scenario Runner / Fleetify Devkit — Logo Kit

Meaning: an execution timeline that branches into another scenario, with the main branch ending in a play button. The mark stays monochrome by default and uses macOS-like rounded geometry.

Assets:
- scenario-runner-logo-dark.svg: wordmark for dark backgrounds
- scenario-runner-logo-light.svg: wordmark for light backgrounds
- scenario-runner-symbol-white.svg: transparent symbol for dark surfaces
- scenario-runner-symbol-black.svg: transparent symbol for light surfaces
- scenario-runner-app-icon.svg: rounded dark app icon, monochrome
- scenario-runner-app-icon-blue.svg: optional blue (#0A84FF) play accent
- scenario-runner-app-icon.png: PNG 512 × 512
- scenario-runner-app-icon-64.png: PNG 64 × 64
- scenario-runner-preview.png: design presentation

Primary palette: #F7F8FA, #111216, #A5A8AE.
Optional accent: #0A84FF (only in the play symbol).
Typography: Inter or SF Pro Display fallback. Logo SVG text is editable.

Usage: use logo-dark on #0C0C0E or charcoal, logo-light on white or soft gray. The square app icon is suited to the app's favicon and GitLab project avatar. Keep clear space around the mark and avoid scaling non-uniformly.
